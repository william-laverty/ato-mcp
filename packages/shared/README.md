# @ato-mcp/shared

The shared tool core for [ato-mcp](https://github.com/william-laverty/ato-mcp): TypeScript
types, Zod schemas, the `Store`/`Embedder` interfaces, and all 13 MCP tool implementations
as pure `(deps, args) => result` functions. Consumed by the `ato-mcp` client package and the
hosted backend so both run identical behaviour.

You probably want [`ato-mcp`](https://www.npmjs.com/package/ato-mcp) — this
package is its engine.
