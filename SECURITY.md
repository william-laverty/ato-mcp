# Security policy

Please report vulnerabilities privately, either through
[GitHub private vulnerability reporting](https://github.com/william-laverty/ato-mcp/security/advisories/new)
or by emailing **security@ato-mcp.com.au**. Do not open a public issue.

You will get an acknowledgement within 72 hours. Reports covering the `ato-mcp`
npm client, `api.ato-mcp.com.au`, or `ato-mcp.com.au` are all in scope.
